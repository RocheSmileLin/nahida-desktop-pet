# 部件快速提取 Part Extract —— 使用说明

> 插件版本 **v1.2** ｜ 位置：`3D 视图 → 按 N → 侧栏「部件提取」`
> 源码：`E:\QQTwinBot\_3d\addons\part_extract.py`
> 安装位置：`%APPDATA%\Blender Foundation\Blender\5.2\scripts\addons\part_extract.py`
> ⚠️ 改过插件文件后要**重启 Blender**（或偏好设置里关掉再勾选一次）才会加载新版本。

---

## 0. 这套流程干嘛的

在**别的模型**上找到好看的衣件 → 拆成独立对象 → 缩放对位到你的模型 → 归并进你的模型
（权重自动对到你的骨架、材质变成独立开关）→ **一键导出 PMX** → 在桌宠里能一键开关。

---

## 1. 拆件（从源模型上取衣件）

1. **源对象** = 要拆的大模型（例：`Base-1_1青雀_2_mesh`）
2. 点 **「扫描材质」** → 列表列出每个材质：**勾选框 + 材质名 + 面数 + 高度 z**
   - 认件靠 z：裙子 0.76~1.09 / 上衣 1.07~1.44 / 袜 0.01~1.06 / 鞋 0~0.2（青雀模型实测）
3. 勾选要的材质（可多选）→ 点 **「提取选中材质」**（大按钮）
4. 选项：`每个材质单独成对象` / `材质复制为独立副本`（改名 = 前缀+材质名，**桌宠开关名就是材质名**）/ `自动设为双面` / `提取后隐藏源对象`
5. **原对象永不被改动**；新对象继承父级与修改器（形状位置与源模型一致）

> 几十万面的模型会有进度条，等它跑完（一般几十秒）。

---

## 2. 缩放到合适大小（手动）

- 选中部件 → `S` 缩放、`G` 移动 到你的模型上
- 参考比例 = 你的模型高 ÷ 源模型高（例：纳西妲 1.066 ÷ 青雀 1.686 ≈ **0.63**）
- 想单独看：选中源模型按 `H` 隐藏

---

## 3. 归并到你的模型

1. **目标骨架** = 你的模型骨架（例：`纳西妲_arm`）
2. **目标身体** = 你的模型身体网格（例：`纳西妲_13_主体`，用于补权重）
3. 选项：
   - `权重重定向（同名骨搬运）`：只保留目标骨架上**同名骨**的权重（`下半身 / 上半身2 / 腿…` 能直通）
   - `未知骨改用目标身体最近点补权重`：权重被丢光的顶点，从目标身体最近 3 点取权重
   - `兜底骨`：还补不到就 100% 绑它（默认 `下半身`；留空则跳过）
   - `挂到目标骨架`：设父级 + 加/改骨架修改器（自动把骨架修改器排到最后）
4. **3D 视图里选中要归并的部件（可多选）** → 点 **「归并选中对象」**
5. 结果打印在**系统控制台**：保留骨数 / 补权点数 / 兜底数 / 用的骨 / 材质 / z 范围

> 归并前建议先 `Ctrl+S` 存盘。

---

## 4. 对位检查

点 **「测量与目标身体的贴合度」**（先选中部件）→ 控制台打印：

```
[贴合] 对象名: 点N 最小xx mm 中位xx mm 90%xx mm 最大xx mm 质心x… z…
```

经验值：**最小 5~20mm** 差不多（负数=穿进身体，太大=悬空）。
贴纸类（纹身）如果陷进身体，做法是把顶点投影到身体表面再沿法线外推 1.5mm（问 Hermes）。

---

## 5. ★★ 接物理（让部件跟着飘 · v1.3 新增）

**原理**：MMD 的物理靠骨骼驱动 —— **刚体 = 马达，权重 = 接线**。
部件的权重没接到「物理驱动骨」上，导出再多次也不会飘（跟导出无关）。

面板「接物理（让部件跟着飘）」：

| 项 | 说明 |
|---|---|
| 目标骨架 | 你的模型骨架（和归并共用） |
| **接法** | ① **裙子（环×角度）**：按高度环 + 绕轴角度映射到目标模型的裙摆骨 → 继承它的裙摆物理 ② **通用（最近物理骨）**：按到骨的最近距离取 K 根混合（适合头发 / 披风 / 袖饰） |
| 骨家族前缀 | 留空 = **自动检测**（找数量最多的「前缀_环_扇区」家族，如 `裙摆_0_0`） |
| 最近骨数 K / 衰减距离 | 通用模式用；衰减 3cm 左右合适 |
| 备份原权重 | 默认勾 → `<blend目录>\_backup\_rollback_接物理_日期时间.json` |

操作：**先在 3D 视图选中要接的部件** → 点「接物理（权重 → 物理骨）」。
控制台打印 `部件: 点N | 物理 x% → y% | 骨N组`，**y 明显变大（如 0%→80%）就对了**。

实测（纳西妲 + 青雀裙子）：
- 格子裙 `0% → 100%`、百褶裙 `0% → 100%`（自动认出「裙摆」家族 = 12 环 × 8 扇区，中轴 `x0.000 y0.001`）
- 已在 Blender 里手工接过的裙子，用插件再跑一次结果一致（幂等）

> **什么样的部件才该接物理？** 会飘的（裙子 / 披风 / 头发 / 袖饰）。
> 贴身件（吊带、纹身、手环）**不要接** —— 接了反而会乱晃。
> 只能接到「目标模型已有物理」的骨上；目标模型本身没物理，插件也变不出来。
> ⚠️ 隐藏的部件**无法被选中**（点不中）→ 先在 Blender 里临时显示（`Alt+H`）再选。

**权重和必须 = 1**：MMD 蒙皮要求每个顶点的权重和恰好 1。
和 <1（如 0.48）时桌宠里顶点会被原点拖拽 → **部件散开 / 变形**，而 Blender 里看不出来。
v1.3 的导出体检会报 `权重和≠1 N` 并指名字段 —— 发现后用「接物理」重跑，或找 Hermes 归一化。

## 6. ★ 一键导出 PMX（v1.2 新增）

面板「导出 PMX（一键）」：

| 项 | 说明 |
|---|---|
| 模型骨架 | 你的模型骨架（和上面共用） |
| 导出到 | 留空 = 自动沿用 `model/` 里已有的 PMX（工作流就是覆盖它） |
| **统一贴图到 tex/** | 导出前把所有材质的 MMD 贴图相对路径改成 `tex/<文件名>`，并把不在 `tex/` 的贴图**自动复制进去** ✅ 强烈建议勾 |
| 含物理（刚体/关节） | 头发/裙子会飘；不要就取消 |
| 导出前体检 | 检查每个部件是否都挂了本骨架的修改器、有没有漏权重的点 |
| 只导出可见对象 | ⚠️ 一般**不要**勾：隐藏的部件会被漏掉 |
| 缩放 | 默认 12.5（Blender 米 → MMD 单位） |
| 贴图复制 | 默认「复制（跳过已存在）」 |

点 **「检查并导出 PMX」** → 控制台打印：体检结果 / 贴图统一情况 / 选中对象数 / 输出路径与大小。

**内部做的事**（不用你管）：选中「骨架 + 骨架下所有网格 + 物理刚体/关节」→ 用 mmd_tools
正确参数导出（`sort_materials=False`、`visible_meshes_only=False`、`SKIP_EXISTING`）→ 还原你的选择。

> ⚠️ 导出前建议 `Ctrl+S`。

---

## 7. 桌宠侧收尾

1. 想改开关名就先改材质名（材质名 = 桌宠里那个开关的名字）
2. 点 **「导出部件清单(给桌宠)」** → 生成 `parts_manifest.json`
3. 把清单交给 Hermes → 改 `js/settings/20-parts.js` 的 `PART_TREE`（不改的话桌宠里点开关没反应也不报错）
4. 导出 PMX → 重启桌宠（F5）

---

## 已知注意点（踩过的坑）

- **贴图必须都放 `tex/` 并让材质的 `texture_rel_path = tex/文件名`**：mmd_tools 导出时**优先用材质的相对路径字段**，
  光改图片数据块的 `filepath` 没用 —— 所以面板里的「统一贴图到 tex/」复选框就是干这个的（勾上再导一次即可）。
- 权重重定向只认**骨名完全一致**；对不上的一律丢弃再由「最近点补权」兜住。
  想保留裙摆摆动（`スカート_*` → 纳西妲 `裙摆_*`）→ 用 **v1.3「接物理 · 裙子（环×角度）」**（已从「插件暂不做」变成一键）✅
- **权重和 ≠1 部件不会飘/会变形**：导出体检的 `权重和≠1` 检查（v1.3 新增）。
- 拆分出来的大件很占体积（青雀 8 双鞋≈32 万面），不用的删掉；导出时不要带源模型。
- 改完记得 `Ctrl+S`；`is_dirty` 标志在本项目上不可靠。

> 适用：`E:\QQTwinBot\_3d\纳西妲完美版_骨骼中文化.blend`（Blender 5.2 中文界面）
> 配套工具：`_3d\tools\查看骨骼绑定.py`（只读，不会改你的东西）
> 生成时间：2026-10-17

---

## 〇、先搞清一件事：Blender 的「绑定」= 两样东西

| | 是什么 | 在哪看 |
|---|---|---|
| ① **骨架修改器** | 这件衣服"跟着哪副骨架动" | 属性 → **修改器属性**（扳手图标）→ `骨架` 那一行 → **物体** |
| ② **顶点组** | 每个组名 = **一根骨的名字**，组里的每个顶点带一个 0~1 的**权重** | 属性 → **物体数据属性**（绿色三角）→ **顶点组** |

规则（记住这三条就不会迷糊）：
1. **顶点组名必须和骨骼名一模一样**，差一个字就完全不生效，而且**不报错**；
2. 一个顶点可以同时属于多个顶点组（多根骨按权重比例混合驱动它）；
3. 权重和应该 ≈ 1（工具里会给出"权重和≠1 的顶点数"）。

## 一、查：这件衣服绑了哪些骨（4 种方法，从易到精）

### 方法 1｜顶点组列表（最快，看"有哪些骨"）
1. 物体模式，点选部件（比如 `浅蓝色文胸`）；
2. 属性编辑器 → **物体数据属性**（绿色三角）→ **顶点组**；
3. 列表里每一行就是一个骨骼名 —— 有几行就说明这件衣服被几根骨影响。

底部 4 个按钮的作用：
- **选择**：把这个组影响到的顶点全部选中（可以切到编辑模式看它们在哪）；
- **取消选择**：取消；
- **指定 / 移除**：把当前选中的顶点加入 / 移出这个组（改权重就靠这两个）。

### 方法 2｜看单个顶点被谁影响（最准）
1. 物体模式按 `Tab` → 编辑模式；
2. 选一个或几个顶点（框选/按住 Shift 多选）；
3. 按 `N` 打开侧栏 → **条目** → **顶点权重** 一栏；
4. 那里会列出：**骨名 + 这个顶点的权重**，一目了然。

### 方法 3｜用颜色看权重（最直观，看"哪块归哪根骨"）
1. 点选部件 → `Ctrl+Tab` → **权重绘制**；
2. 右侧顶点组列表点选一根骨 → 模型上的颜色就是这根骨的权重（**红=1，蓝=0**）；
3. 顶部「权重绘制选项」里把 **零权重** 勾上，能把没权重的区域也显出来。

### 方法 4｜脚本一次看全（推荐，尤其是排查错绑）
Blender 右上角工作区切到 **脚本 (Scripting)** → 文本编辑器「打开」→ 选
`E:\QQTwinBot\_3d\tools\查看骨骼绑定.py` → 先点选要查的部件 → `Alt+P` 运行。

输出长这样（真实实测，粉红色披肩）：

## 二、改：4 种改法，对号入座

### 改法 1｜精修几个点（编辑模式 + 指定/移除）
1. `Tab` 进编辑模式，选好顶点；
2. **物体数据属性** → 顶点组列表点中目标骨；
3. 下面 **权重** 填数值（0~1）；
4. 点 **指定** = 用这个值**覆盖**这些点在该组的权重（不是相加）；
   - 想去掉某根骨对这些点的影响 → 点 **移除**。

### 改法 2｜大面积刷权重（权重绘制）
1. `Ctrl+Tab` → **权重绘制**，右侧选中目标骨；
2. 左侧工具设置调 **半径 / 强度**，直接在模型上刷（按住 `Ctrl` 是反向擦除）；
3. 刷完按 `F3` 搜 **归一化全部**（Normalize All）把权重和拉回 1；
4. 边缘不光滑 → `F3` 搜 **平滑顶点组权重**，多刷两遍。

### 改法 3｜整件重新绑（自动权重）
1. 先把旧顶点组全删（顶点组列表右上角 `✕`，或全选后删）；
2. 先点部件、再 **按住 Shift 点骨架**（两个都选中）；
3. `Ctrl+P` → **附带自动权重**。
   ⚠️ 自动权重是按"骨骼包裹"算的，衣服离身体远、面片很薄或双层时会算错
   → 绑完**一定**用脚本复查（方法 4）。

### 改法 4｜抄别的东西的权重（最靠谱，披肩/臂饰就是这么干的）
让新衣服的变形和身体皮肤**完全同源**，就不会出现"衣服动、皮肤不动"的错位：
1. 选中衣服 → 修改器属性 → 添加 **数据传递 (Data Transfer)**；
2. **源** = 身体网格（`纳西妲_13_主体`）；**源类型** 面数据点；
3. 勾选 **顶点组权重（VGROUP_WEIGHTS）**，点 **生成数据层**；
4. 应用这个修改器（⚠️ 有形态键的网格不能应用，见坑 4）。

我的做法更进一步：逐顶点找最近的几个**皮肤**顶点，只保留白名单里的骨
（披肩用的是 `上半身 / 上半身2 / 上半身3 / 肩.L/R / 臂.L/R / 臂扭/臂扭1/2/3`），
再归一化 —— 这样"该跟大臂的部分"自然落到大臂上，不会混进头发/裙摆骨。

## 三、五个必踩的坑

1. **顶点组名 ≠ 骨骼名** → 完全无效、**不报错**。改名时两边一起改，或用脚本查死组。
2. **修改器指向错骨架**：这个 .blend 里有 3 副骨架
   （`纳西妲_arm` / `芙提雅-驰掣 草莓甜心权重裙… _arm` / `瑟瑞斯-悠游 碧波浮游`）。
   `粉红色围裙 / 粉红色内裤 / 粉红色披肩` 曾经挂在**芙提雅**那副上 → 播放舞蹈时身体动、围裙不动。
   查法：修改器属性里看 `骨架 → 物体` 是哪一副（脚本第 3 行也会打印）。
3. **父级设成骨架 ≠ 蒙皮**：父级只负责"跟着骨架物体走"，真正让顶点被骨骼拉扯的是
   **Armature 修改器**。两个都要有。
4. **有形态键的网格不能「应用」修改器**（会自动失败或错位）：
   先删/烤掉形态键，或者用"抄权重"的方式直接写顶点组（不新增修改器）。
5. **手动转骨测试可能无效**：`纳西妲_arm` 上挂着动画 `摇一摇_bone`，
   每帧都会被动画覆盖 → 你在姿态模式转骨头，画面会立刻被拉回去。
   要手动测，先在 **Dope Sheet → 动作编辑器**里把动作清掉（或切到没有动作的骨架），
   再转骨。另外注意有没有开 **自动关键帧**（时间轴上红色的圆点）。

## 四、改完怎么验收（顺序别乱）

1. 跑脚本复查：**死组 0 / 无权重顶点 0 / 权重和≠1 的顶点 0**；
2. 转骨或播动画看变形（注意坑 5）；
3. **`Ctrl+S` 存盘，然后重新打开文件再看一次**——内存里对不等于存盘对
   （这个项目已经踩过三次"改完没落盘"：编辑模式下的写入会被 BMesh 覆盖）；
4. 导出 PMX 前检查：一个网格只跟**一副**骨架绑定；材质名要和桌宠开关表一致
   （对照表 `_3d\部件材质对照.json`）。

  （`后发_14_1 / 15_1 / 16_1` + `头`，合计约 93 个顶点、权重和 46）→ 头发甩的时候文胸有
  这些点会跟着轻轻动。你说过"动作看起来没问题"，所以我没动；要清就把它们并进 `上半身2`。

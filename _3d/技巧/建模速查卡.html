Blender 做衣服 · 一图看懂

① 网格三要素 —— 面就是"布"

② 做一件衣服 = 这 5 步

第 1 步
Shift+A
加"圆柱体"
F9 改：顶点24 / 半径0.10 / 深度0.32
›
第 2 步
Ctrl+R
加 3~4 圈环线
（没环就没法局部塑形）
›
第 3 步
S …
逐圈缩：肩0.78 → 胸0.88 → 腰0.95 → 下摆1.30
再 S Y 0.85 压扁
›
第 4 步
X → 面
剪掉顶盖=领口
Alt+左键 选边界 → S Z 0 变直
›
第 5 步
实体化
修改器 → 生成 → 实体化
厚度 0.004 · 偏移 1
加完这 5 步就是一件能看的衣服；想让它"跟着人动"，还要补 骨架修改器 + 数据传递权重 + Ctrl+P 父级。

③ 只有 6 个键要记

Tab切"物体模式 / 编辑模式" —— 动不了先按它
G / S / R移动 / 缩放 / 旋转；后接 X/Y/Z 锁轴，或直接打数字（如 S 1.2）
S Z 0沿 Z 压平 ⇒ 波浪下摆立刻变直线
E挤出：拉出一片新面（做袖筒、裙摆）
Ctrl+R加环线：形状要顺全靠它
Alt+左键选一整圈（选下摆/袖口/领口的边界环）
O比例编辑：像拽橡皮一样柔和变形
Ctrl+Z / Ctrl+S撤销 / 保存 —— 每做对一步就保存

④ 你这具模型的尺寸（建模按这个来，单位：米）

下摆 / 领口 / 袖口z = 0.565 / 0.875 / 0.80
半宽（半径）肩 0.063 · 胸 0.066 · 腰 0.080 · 胯 0.106（宽松再加 0.02~0.03）
单臂上臂围 24.8cm（半径约 0.04），袖口 z = 0.80
朝向 / 左右面朝 −Y；左 = +X

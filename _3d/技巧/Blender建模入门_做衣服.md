# 零基础：用 Blender 给纳西妲做衣服（手把手）

> 目标文件：`E:\QQTwinBot\_3d\纳西妲完美版_骨骼中文化.blend`
> 你只需要会三件事：**选中东西 → 用 G/S/R 改变它 → 用 E/Ctrl+R 加工它**
> 本文所有数值都是你这具模型上实测的（单位：**米**）

---

# 第一部分 · 先搞懂 4 个概念（5 分钟）

### 1. 两种模式（最重要的分界）
| 模式 | 能干什么 | 怎么进 |
|---|---|---|
| **物体模式** | 选择/移动**整个对象**（如"头饰"、"连衣裙"） | `Tab` |
| **编辑模式** | 编辑对象内部的**点/边/面** | `Tab` |

🔴 **90% 的"我怎么选不中/动不了"都是模式不对。** 动不了先按 `Tab` 看一眼。

### 2. 网格的三要素
- **顶点（点）**：一个小点
- **边**：两个点连成的一条线
- **面**：三个以上点围成的一片"布" ← **面就是布**

```
   点        边          面
   •        •——•      •——•
                       |  |
                       •——•
```

### 3. 选择"点/边/面"要切换
进编辑模式后，**左上角有三个小图标**（或按 `1` `2` `3`）：
`1` = 点选择 · `2` = 边选择 · `3` = 面选择（**做衣服最常用 `3`**）

### 4. 视图操作（鼠标）
| 操作 | 按键 |
|---|---|
| 旋转视角 | **中键拖**（滚轮按住拖） |
| 平移视角 | `Shift+中键拖` |
| 缩放 | 滚轮 |
| 正视图（从前往后看） | 小键盘 `1` |
| 侧视图 | 小键盘 `3` |
| 顶视图 | 小键盘 `7` |
| 聚焦选中的东西 | 小键盘 `.` |
| 框显全部 | `Home` |

⚠️ 笔记本没有小键盘：`文件 → 用户设置 → 输入 → 勾选"模拟数字键盘"`，然后用主键盘上排数字。

# 第二部分 · 手法速查（背下来这 10 个就够用）

| 我要干嘛 | 按键 | 说明 |
|---|---|---|
| 选中 | 左键点 | `Shift+左键` = 加选；`Alt+A` = 全部取消 |
| 框选一堆 | `B` 然后拖 | `Ctrl+右键拖` = 套索 |
| 选一整圈 | `Alt+左键` 点一条边 | ★ 选衣服的"边缘环"就靠它 |
| 选相连的一整块 | `L`（鼠标停在上面按） | 选整片布 |
| **移动** | `G` → 动鼠标 → 左键确认 | 再加 `X`/`Y`/`Z` 锁轴：`G` `Z` |
| **缩放** | `S` → 动鼠标 → 左键确认 | 锁轴：`S` `Z`；输数字：`S` `1.2` |
| **旋转** | `R` → 动鼠标 → 左键确认 | 锁轴：`R` `X` |
| **精确值** | 按下 `G/S/R` 后**直接打数字** | 例：`S` `0.8` `回车`；`G` `Z` `0.02` `回车` |
| **挤出一片新的布** | `E` | 把选中的边/面往外拉出新面 ★★ |
| **加一圈边** | `Ctrl+R` → 滚轮加条数 → 左键 → 左键 | 形状要顺全靠它 |
| 删除 | `X` → 选"面/边/顶点" | 剪下摆、剪袖口 |
| 把选中的围成一个面 | `F` | 补洞用 |
| 合并点 | `M` → "到中心" | 收口
| 撤销 / 保存 | `Ctrl+Z` / `Ctrl+S` | 满意了**先保存** |

**取消操作** = `右键` 或 `Esc`（在还没确认的时候）

# 第三部分 · "怎么搞出一个面来？"（你问的第一个问题）

面的来源只有三条，**做衣服用第 1 条**：

### 路线 1：加一个"图元"，它自带面（最省事 ✅）
1. 先回到**物体模式**（`Tab`）
2. 把鼠标放在要做衣服的位置 → 按 **`Shift+A`** → **网格 → 圆柱体**
3. **马上按 `F9`**（左下角会弹出一个"添加圆柱体"面板）→ 改：
   - **顶点数 = 24**（越大越圆滑；做衣服 24 够用）
   - **半径 = 0.10**、**深度 = 0.32**
4. 现在你就有了一个"布筒"—— 它的侧面**全部是面**！直接 `Tab` 进去改形状就行

> 也可以 `Shift+A` → 网格 → **平面**（1 个面）→ 按 `E` 一点点挤成布片，适合做围裙这类片状衣物。

### 路线 2：用 `F` 把点围成面
编辑模式 → 选 3 个以上相邻的点 → 按 `F` → 出现一个面。

### 路线 3：用 `E` 挤出新面
选中现有的面/边 → `E` → 拖动 → 长出新的一段（袖筒、裙摆都可以这样拉出来）。

# 第四部分 · "怎么改形状？"（你问的第二个问题）

改形状 = **选中 → G/S/R**，反复三步：

1. **转视角**（中键拖）看清楚要改哪
2. **选中**（`3` 面选择 / `1` 点选择；`Ctrl+R` 先加一圈边，才能局部改）
3. **G / S / R** 改，然后切到**正视图（小键盘 1）和侧视图（小键盘 3）**各看一眼

### 三个让形状变好看的技巧
| 技巧 | 怎么做 | 效果 |
|---|---|---|
| **加环线** | `Ctrl+R` → 滚轮加几圈 → 左键 → 左键 | 只有加了环，才能局部缩放成型 |
| **比例编辑**（柔和拉扯） | 按 `O` 打开（顶栏会出现圆图标）→ 再用 G/S/R | 像拽橡皮，周围跟着圆滑变形；滚轮调影响范围 |
| **平滑** | 编辑模式选中要顺的地方 → 顶栏 **网格 → 平滑顶点**（重复 2~3 次） | 去掉坑洼 |
| **沿 z 压平边缘** | 选中边缘环（`Alt+左键`）→ `S` → `Z` → `0` → 回车 | ★ 波浪/锯齿的下摆立刻变直线 |

# 第五部分 · 实战：从圆柱做一件 T 恤（逐键操作，照做即可）

### 目标（全部用你的实测尺寸）
- 下摆 `z = 0.565`、领口 `z = 0.875`、袖口 `z = 0.80`
- 宽度：肩 0.075 → 胸 0.085 → 腰 0.095 → 下摆 0.13（= 胯 0.106 + 宽松）
- 厚度方向压扁：`Y` 方向 × 0.85（胸口前后厚 11.2cm < 左右宽 13.2cm）

### 步骤

**① 生成基础筒**
1. 物体模式 → 鼠标放在人物胸口 → `Shift+A` → 网格 → **圆柱体**
2. 按 `F9` → **顶点数 24 · 半径 0.10 · 深度 0.32**
3. `G` `Z` `0.715` `回车`（中心高度 = (0.565+0.875)/2 ≈ 0.715）
4. `Tab` 进编辑模式 → 按 `3`（面选择）

**② 加 3 圈环线（为了能局部塑形）**
5. `Ctrl+R` → 鼠标移到圆柱上出现一圈黄色预览 → 滚轮滚到 **4 条** → 左键 → 右键
   （如果只想要 1 条：`Ctrl+R` 后直接左键 → 左键）

**③ 逐环缩放，做出"上窄下宽"的 T 恤形状**
6. 切到**正视图**（小键盘 `1`），框选（`B`）最上面那一圈 → `S` `0.78` `回车`
7. 第二圈 → `S` `0.88` `回车`
8. 第三圈 → `S` `0.95` `回车`
9. 最下面那一圈 → `S` `1.30` `回车`
10. 全部选中（`A`）→ `S` `Y` `0.85` `回车`（前后压扁）

**④ 剪出领口**
11. 按 `3` 面选择 → 选中圆柱**顶面**（点顶面中间那一块）→ `X` → **面**
    （顶盖被删掉 → 变成一个开口 = 领口）
12. 想要**宽领**：再选顶环周围一圈面删掉 → 用 `Alt+左键` 选边界环 → `S` `Z` `0` 让它变平

**⑤ 剪出袖口 / 做短袖**
13. 最简单的做法：**再做一个圆柱当袖子**
    - 物体模式 → `Shift+A` → 圆柱体 → `F9`：**顶点数 16 · 半径 0.05 · 深度 0.11**
    - `R` `Y` 或 `R` `X` 转到和手臂一个角度（手臂从肩到肘是**斜向外下方**，约 30°）
    - `G` 挪到肩关节位置（`x = ±0.10, z = 0.83`）
    - 把袖子的一端（靠里的那圈）选中 → `S` `1.15` 稍微放大，让它套在躯干外面
    - ⚠️ 袖子的另一端也删掉顶盖，才是"袖口"
14. 觉得袖子太麻烦就先不做袖子（做无袖/吊带也可以）

**⑥ 给衣服厚度**
15. 回到**物体模式** → 选中衣服对象 → 修改器属性 → 添加修改器 → 生成 → **实体化**
16. **厚度 = 0.004**（薄棉布感；想要"厚壳"就用 0.015）
17. 偏移 = **1**（向外长）

**⑦ 让衣服跟着骨骼动（关键，不做就是"死的"）**
18. 修改器 → 变形 → **骨架** → 对象选 `纳西妲_arm`
19. 选中衣服 → `Shift+左键` 加选骨架（**骨架要是"亮一点"的那个**）→ `Ctrl+P` → **物体**
20. **权重**：修改器 → 生成 → **数据传递**：
    - 源物体 = `纳西妲_13_主体`
    - 勾选 **顶点数据 → 顶点组** → 映射 = **最近顶点·面插值**
    - 点 **「生成数据层」** → 再 Ctrl+A 应用（或点面板里的"应用"）

**⑧ 材质（名字决定桌宠里能不能开关）**
21. 属性 → 材质属性 → **新建** → 命名 `T恤`（**这就是桌宠开关名**）
22. 着色器编辑器里，把贴图节点按 `F2` **改名成 `mmd_base_tex`**（一个字都不能错）
23. 设置 → **双面显示** 勾上

**⑨ 验收**
24. 物体模式绕一圈看：有没有洞、有没有穿模
25. 给 `腕.L` 转 30°（姿态模式）看袖子跟不跟着动 → 然后 `Alt+R` 复位
26. **`Ctrl+S` 保存**

# 第七部分 · 常见问题

| 症状 | 原因 | 解法 |
|---|---|---|
| 点什么都没反应 | 在**物体模式**，或没选中对象 | `Tab` 切模式；先左键点一下对象 |
| 选中了但移不动 | 选错了模式/被锁轴 | 看左上角是点/边/面选择；按 `Alt+A` 重选 |
| 新加的面看不见 | 面"反了"（背面剔除） | 编辑模式 `A` 全选 → `Shift+N` 重算法线 |
| 衣服是"死"的，不跟手 | 缺骨架修改器 / 缺权重 / 缺父级 | 回到第 ⑦ 步三件套 |
| 桌宠里衣服是纯白 | 贴图节点名字不是 `mmd_base_tex` | 选中节点 `F2` 改名 |
| 桌宠里开关点了没反应 | `PART_TREE` 里没有这件衣服的名字 | **告诉我**，我加（改完要 F5 + 重启桌宠） |
| 下摆是波浪/锯齿 | 边界不在一个平面上 | `Alt+左键` 选边界环 → `S` `Z` `0` |
| 越做越乱 | 没保存 / 撤不回去 | **每做对一步就 `Ctrl+S`**（Blender 自动存 `.blend1` 备份） |
| 身体起伏被"复印"到衣服上 | 用"沿法线外扩"会继承皮肤坑洼 | 用 `Ctrl+R` 加环后逐环 S 缩放成型，或用「网格 → 平滑顶点」；**别直接沿法线外扩** |

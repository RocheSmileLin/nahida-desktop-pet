## 2. 白 T 恤：三条技术路线

### 路线 A — 改贴图（最省，半天内）
把 `连衣裙-体` 改白色、删/隐掉 `连衣裙-裙` `裙2` `体饰`（裙摆）。
- ✅ 成本极低、完全可逆、能先验证配色
- ❌ 形状仍是**贴身胸衣**（有腰身、非落肩、无袖筒），观感 ≈ 白色打底衫，不是参考图那种宽松 T
- 适合：**当配色预览稿用**（第 3 节第 2 步）

### 路线 B — 脚本新建 T 恤几何（推荐，2~3 轮迭代）
以 `body_hexie` 身体表面为底：
1. 取躯干+上臂表面点 → 沿法线外扩 1.5~2.5 cm（=宽松感，参数化）
2. 按轮廓表切边界：**领口**（z≈0.90，肩线处）、**短袖口**（上臂 1/3，z≈0.80）、**下摆**（z≈0.52，盖住裤腰 0.71 以下）
3. 生成壳面 → 平滑 → 面法线朝外、`use_smooth=True`
4. 权重：从最近的身体顶点**按名复制**（上半身2 / 上半身 / 下半身 / 肩 / 腕），下摆主要给 `下半身/腰`
5. 独立材质 `T恤`（纯白 + 轻微明暗，也可做颈部/袖口滚边），`name_j` 同步
- ✅ 形状最接近参考图、可参数化反复调（宽松度/袖长/下摆/领口都能给你一组数字调）
- ⚠️ 需要 2~3 轮"出图→你提意见→改参数"
- ⚠️ 需要独立材质名 → 桌宠 `PART_TREE` 加一行（我做）

### 路线 C — 外部素材
从别的 MMD 模型里拿现成的宽松 T 恤/短裤件改权重接进来。
- 项目内**没有**这类素材（已扫：只有纳西妲本体与备份），需要你提供带居家服的模型文件
- 有成熟配方（跨模型换件：骨骼锚点算缩放、权重按名搬运、材质去重），但素材质量决定成败

**建议：先按 A 出配色效果图 → 你确认颜色/观感 → 再按 B 建形状。**（符合你"先设计后实现"的习惯）

## 4. 风险与坑（都是本项目踩过的真实坑）

1. **宽松衣服在动作下穿模**：现有动作里有「摇腿」「坐姿2」等大幅腿部动作，宽出身体 2 cm 的下摆/袖口可能穿进腿。
   → 选项：接受轻微穿模（截图看是否明显）/ 收窄到 1.2 cm / 下摆权重只给 `下半身`（不动） / 后续加布料软体（大工程，不建议本轮做）
2. **改裤子颜色不是刷整张图**：裤子与连衣裙**共用 `体1.png`(2048²)** → 必须**先定位裤子的 UV 岛**（估计只有几十 px）再局部改，否则会把连衣裙一起改掉。已有现成定位脚本。
3. **`连衣裙-裙2` 开着背剔（`use_backface_culling=True`）**：新件若照抄该材质设置，部分面会"凭空消失"。
4. **材质名 = 桌宠开关**：新件必须有自己的 `mmd_material.name_j`（PMX 导出与 three.js 都读这个字段），且导出前**断言无重名**。
5. **PMX 材质顺序 = 对象编号**（主体必须最后绘制）→ 新增对象命名要跟着排。
6. **改完必须重导 PMX + 重启桌宠**才在浏览器里生效（模型只在启动时加载）。

## 1. 四条路线，先选一条

| 路线 | 需要什么 | 难度 | 自由度 | 推荐场景 |
|---|---|---|---|---|
| **A. 从身体"复制壳 + 实体化"** | 只要 Blender | ★ 低 | 中 | **第一次做衣服，首选** |

## 2. 路线 A：从身体复制壳（推荐第一次做）

**核心思路**：衣服 ≈ 身体表面往外套一层。所以直接复制身体的面，加"实体化"给厚度，再剪掉不要的部分。

1. 打开 `.blend` → 大纲视图选中 **`纳西妲_13_主体`**
2. `Tab` 进编辑模式 → 顶栏模式切到**面**选择
3. 属性编辑器 → **材质属性** → 点选 `body_hexie` → 点下面的 **「选择」**（= 选中全身皮肤面）
4. 把不要的部分去掉：按 `Alt+A` 取消全选 → 用**框选/套索**（`B` / `Ctrl+右键拖`）配合视图旋转，只留躯干这一圈
   - ★ 偷懒办法：不做这一步，先整身复制，最后统一切
5. `Shift+D`（复制）→ 右键（留在原地）→ `P` → **「选中项」**（分离成新对象）
6. `Tab` 回物体模式 → 选中新对象 → **修改器属性 → 添加修改器 → 生成 → 实体化**
   - **厚度 = 0.016**（1.6 cm 宽松感；下摆想更松可以再单独放大）
   - **偏移 = 1**（向外长）
   - ⚠️ **顶点组会自动继承**（实体化生成的内层顶点同样带权重）→ **不用重新刷权重** ✅
7. 剪出下摆 / 袖口 / 领口：`Tab` 进编辑模式 → 选中不要的环/面 → `X` → **面**
8. ★★ **让边缘变光滑（关键一步）**：删完边缘会是锯齿状 →
   - `Alt+左键` 点边界，选中**整个边界环**
   - 按 `S` → `Z` → `0` → 回车（沿 Z 缩放为 0 ⇒ **边界立刻变成一条水平直线**）
   - 想更圆顺：顶栏 **网格 → 平滑顶点** 重复 2~3 次
9. 材质（见第 4 节）
10. 验收：物体模式转一圈看 + 给 `腕.L` 转个角度看衣服跟不跟着动

## 3. 路线 B：从零建 + 「数据传递」自动继承权重

1. `Shift+A` → 网格 → **圆柱体**（顶点数 **24**）→ 摆到躯干位置、按尺寸表缩放
2. 编辑模式塑形：`Ctrl+R` 加环、`S` 缩放选环、`E` 挤出、`Alt+M` 合并
3. 加「**实体化**」修改器给厚度（0.004~0.008，薄衣；外套 0.015）
4. ★★ **权重不用手刷** —— 用**数据传递**：
   - 物体模式 → 修改器属性 → 添加修改器 → **生成 → 数据传递**
   - **源物体 = `纳西妲_13_主体`** → 勾选 **顶点数据 → 顶点组**（映射 = 最近顶点·面插值）
   - 点 **「生成数据层」** → 再点 **「应用」**（或 Ctrl+A 应用修改器）
5. 或者手动刷：`Ctrl+Tab` → 权重绘制 → 选骨骼 → 刷
6. ⚠️ **必须补两样**不然不跟骨骼动：
   - **修改器 → 变形 → 骨架**，对象 = `纳西妲_arm`
   - 选中衣服 → `Shift+左键` 加选骨架 → `Ctrl+P` → **「物体」**（父级）

## 4. 材质（这一步决定桌宠里能不能开关）

1. 属性 → **材质属性 → 新建** → 命名，例如 `外套`
   - ★★ **这个名字就是桌宠里的开关名**（PMX 导出 / 桌宠都读 `mmd_material.name_j`）
2. 材质属性 → **设置 → 名称 / 英文名称**（= `name_j` / `name_e`）填**同一个名字**
3. **基础贴图节点必须叫 `mmd_base_tex`**：
   - 着色器编辑器里选中贴图节点 → `F2` 改名 → 输入 `mmd_base_tex`
   - ⚠️ mmd_tools 导出时**只按这个名字找**；找不到 ⇒ PMX 里没贴图 ⇒ **桌宠里那块是纯白**
4. 材质设「双面显示」（`mmd_material.is_double_sided` 勾上；Blender 侧关掉背面剔除）
5. ⚠️ **一件衣服一个独立材质**：多个部件共用材质 ⇒ 桌宠开关会连动

## 5. 导出 PMX + 接到桌宠（硬规则，照抄）

**你（Blender）**：选中所有部件对象 + 骨架（**最后点骨架**，让它是活动对象）→ 文件 → 导出 → **pmx**
| 参数 | 值 | 为什么 |
|---|---|---|
| scale | **12.5**（默认，别改） | 与导入时 0.08 互逆，保证尺寸一致 |
| visible_meshes_only | **False** | ★ 关掉只导出可见 ⇒ 隐藏的部件会全丢 |
| copy_textures_mode | `SKIP_EXISTING` | 图已存在就不重复拷 |
| sort_materials | False | |

**我（桌宠侧）**：`js/settings/20-parts.js` 的 `PART_TREE` 加一行（跨对象可写多个材质名）+ `pet_settings.json` 加默认状态 → 改完 `node --check` 逐段校验。
⚠️ **这张表不改，按钮点了没反应、也不报错** —— 所以每次加衣服都要告诉我。

## 6. 硬规则与坑（都是本项目踩过的）

1. **基础贴图节点名字错了 ⇒ 桌宠里是白块**（不是"没贴图"，是导出时找不到那个名字）
2. **法线朝向**：MMD 壳的法线常是**混向**的（本模型实测 556 个顶点朝内）→ 做外扩/实体化前先 `Shift+N`（重算法线，设置里勾「内部」）
3. **外衣必须比内层宽**：逐 z 对照 `max|x|`，否则内层会"顶穿"（表现为花瓣状交错）
4. **从零建的件必须补权重 + 骨架修改器 + 父级**，三样缺一件就不动
5. **`Ctrl+Z` 可撤销**（我的脚本改动也能撤）→ 满意了**立刻 `Ctrl+S`**
6. 想验证"有没有跟骨骼动"：给 `腕.L` / `膝.L` 转 30° 看衣服跟不跟，然后 **复位**（`Alt+R`）
7. 文件随时会被"另存为"改名 → 备份/导出都以当前 `bpy.data.filepath` 为准

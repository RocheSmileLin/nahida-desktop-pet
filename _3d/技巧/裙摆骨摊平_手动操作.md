# 裙摆骨「圆锥面 → 平面」手动操作步骤

> 目标：把 195 根裙摆骨从圆锥面**摊成一个平面**（即每根骨的方向变成水平 = 平行于 XOY 面）
> 方式：**只改姿态（旋转）**，骨头位置不动、父子链不动、权重不动 ⇒ 随时 `Ctrl+Z` 可回退
> 生成时间：2026-10-16

---

## 一、现状实测数据（改之前先对照，确认是同一状态）

```
裙摆骨 195 根 = 13 环 × 15 扇（骨名前缀 `裙摆_`）

方向 dz（骨头的指向，0 = 水平，负 = 朝下）
   环0 ~ 环11   全部 ≈ -0.9020  ← 12 环的指向【本来就完全一致】
   环12          +0.9711        ← 唯一朝上的一圈（当初刻意设计成"驱动空气"）

骨头 Z    : -0.8822(环0) → -1.1528(环12)，每环下沉约 0.0227
骨头XY半径: 0.057 → 0.297（越往下越往外）
骨长      : 0.0185 ~ 0.0800
父级      : 环0 的 15 根挂【下半身】；其余每根挂【同扇的上一环】= 链式
```

**关键结论**：形成圆锥的是**骨头的位置分布**（沿锥面一圈圈往下往外铺），
**不是骨头朝向**——12 环的朝向本来就是同一个方向。

## 三、操作步骤（Blender 5.2）

### ① 选中要改的骨（推荐用大纲视图过滤）
1. 右上角 **大纲视图 (Outliner)** → 找到骨架 `纳西妲_arm` → 展开到骨骼层
2. 大纲视图顶部的**搜索框**里输入 `裙摆_` → 列表只剩裙摆骨
3. 点第一根 → `Shift` + 点最后一根 → **全选 195 根** hmm 注意：大纲里选中的骨在视图里也会选中 ✓

> 只想先试一扇（13 根）：搜索框输入 `裙摆_0_` 就是环0 那 15 根
> 想只试一根：只选 1 根（**强烈建议先只改 1 根试手感** ✓）

### ② 进姿态模式
- 视图里点骨架 → `Ctrl+Tab` 切到**姿态模式**（或左上角模式下拉里选"姿态模式"）

### ③ 旋转（关键：用【骨骼自身轴】）
```
按 R            （进入旋转）
连按两次 X      （XX = 绕骨骼【自身 X 轴】，只按一次是绕全局 X ✗）
输入 64.5       （或 76.2）
回车
```
- 如果转的方向反了（越转越往下）→ 输入 **`-64.5`** ✓
- 如果 `R X X` 不是你要的那个轴 → 试 **`R Z Z`**（自身的 Z 轴）✓
- `R` 之后按 `Esc` 可取消 ✓

### ④ 批量做
- 确认了"轴 + 符号"之后 → 重新全选 → 同一操作重复一遍即可 ✓
- 环12 那 15 根单独选、单独用 `76.2` ✓

### ⑤ 存盘
- 改之前先 `Ctrl+S` 存一份 ✓（转错随时 `Ctrl+Z` 回退 ✓）

## 四、为什么"绕自身轴旋转"就等于你要的"绕锥顶旋转"

- 姿态模式下，骨头的旋转**永远以自己的骨头为轴心** ⇒ 骨头位置不会跑 ✓
- 每根骨只要**方向**转成水平，它就**落在水平面里** ✓
- 因为 12 环的朝向本来就一致 ⇒ **同一扇的 13 根骨用同一个角度就能一起转平** ✓
- 左右两侧的骨轴可能是镜像的 ⇒ **符号可能相反** ⇒ 所以先试 1 根、看清符号再批量 ✓

## 五、改完怎么验收

改完说一声，我来量两个数（只读、不动你的场景）：
1. **方向 dz 是否全部 ≈ 0**（= 真的平了 ✓）
2. **骨头位置是否一根都没动**（对比改前的 Z/XY 半径 ✓）
3. 出一张对比图 ✓

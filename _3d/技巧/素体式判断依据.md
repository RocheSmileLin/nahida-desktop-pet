# MMD 素体「式」判断依据（TDA式 / Sour式 / YYB式 / ERM式）

> **用途**：换素体、接入新模型时，快速判断这个身子是哪一家的底子。
> **判断方式**：解析 PMX 的**骨骼命名**（各家流派最硬的指纹），不是看外形。
> **记录时间**：2026-10-11 ｜ 对应模型：`model/纳西妲完美版.pmx`

---

## 一、快速判断表（按区分度从高到低）

| 骨名特征 | 出现情况 | 含义 / 指向 |
|---|---|---|
| `腕捩1` / `腕捩2` / `腕捩3` | **三根** | ★ **YYB 系**（区分度最高） |
| 只有 `腕捩`（单根） | 一根 | ★ **TDA 系** |
| `手捩1` / `手捩2` | **两根** | ★ **YYB 系**（TDA 只有单根 `手捩`） |
| `肩P` | 有 | TDA / YYB 共有（準標準ボーン） |
| `上半身2` | 有 | TDA / YYB / Sour 共有 |
| `下半身2` | **无** | 可排除部分 Sour 系 |
| `足先EX` + `足D`/`ひざD`/`足首D` D链 | 有 | TDA 改造系常见结构 |
| `足IK親` | 有 | 準標準ボーン |
| `全ての親` / `グルーブ` / `グルーブ2` / `センター2` / `両目` | 有 | 準標準ボーン齐全 |

### ⚠️ 準標準ボーン（各家都会补，**不能用来区分流派**）
`グルーブ`、`上半身2`、`腕捩`、`手捩`、`肩Ｐ`、`足IK親`、`両目`、`腰キャンセル`、`足先EX`

这些是 MMD **官方準標準ボーン**，各流派改造时都会补上 —— **单独出现不能定性**，必须看「细分根数」。

## 二、各家流派特征（社区通行说法）

| 式 | 腕捩 | 手捩 | 其他特征 |
|---|---|---|---|
| **TDA式** | 单根 `腕捩` | 单根 `手捩` | 最主流底子；有 `肩P`、`上半身2`；手指 `親指0/1/2` + `人指1/2/3` |
| **YYB式** | **`腕捩1/2/3` 三根** | **`手捩1/2` 两根** | 同有 `肩P`、`上半身2`；体型偏圆润 |
| **Sour式** | 1~2 根 | — | 结构偏写实；有 `上半身2`，部分带 `下半身2` |
| **ERM式** | — | — | 特定几家（如 ERM 式初音）的私有骨架，特征不通用 |
| **Lat式** | 无 | 无 | 旧式，无 `肩P` |

## 三、本项目（纳西妲）实测结论

解析 `_3d/model/纳西妲完美版.pmx`（UTF-16LE 字符串计数）得到：

```
腕捩1 ×2   腕捩2 ×2   腕捩3 ×2     ← 三根 ✅ YYB 特征
手捩1 ×2   手捩2 ×2               ← 两根 ✅ YYB 特征
肩P ×2                            ← 準標準
上半身 ×7  上半身2 ×4  下半身 ×2     ← 有 上半身2
下半身2 ×0                        ← 无
足先EX ×2  左足D/ひざD/足首D ×1     ← TDA 改造系 D 链
足IK親 ×2  全ての親 ×1  グルーブ ×2  グルーブ2 ×1  センター2 ×1  両目 ×1
```

### 结论
**YYB 系素体 + TDA 系风格的足部 D 链改造** —— 原神同人模型里常见的混合体：
拿 YYB 的身子底，再改了足部 IK 链（`足先EX` + D 链）。

## 四、复用手法（以后换素体 / 拿到新 PMX 怎么查）

### 4.1 一键数特征骨名（推荐）

```bash
cd E:/QQTwinBot/_3d
"D:/Python/python39.exe" -c "
b = open('model/纳西妲完美版.pmx', 'rb').read()
for k in ['腕捩1','腕捩2','腕捩3','腕捩','手捩1','手捩2','手捩',
          '肩P','上半身2','下半身2','足先EX','足IK親','全ての親','グルーブ']:
    print('%-10s ×%d' % (k, b.count(k.encode('utf-16-le'))))
"
```

**判读**：
- `腕捩1/2/3` 各有计数 → **YYB 系**
- 只有 `腕捩` 有计数、`腕捩1` 为 0 → **TDA 系**
- `腕捩`/`手捩` 全为 0 → **Lat 式或更旧的底子**

### 4.2 在 MMD / PMX Editor 里目视检查
打开模型的**骨骼面板**，看臂部是否有 `腕捩1`、`腕捩2`、`腕捩3` 三根并列。

## 五、注意事项

1. **判断依据是骨骼结构，不是 100% 权威**。同人改造常把多家特征混在一起。
2. **最可靠的是配布页 / readme** —— 上面会直接写「XX式」。
   本项目素体原配布名留过线索：`纳西妲素体_MDJSN_edit_v1.0_模之屋配布用`（已按需清理）。
3. **不能靠外形判断**：同一"式"被不同人改造后胖瘦差异很大。
4. 换素体后记得同步：`js/settings/20-parts.js` 的 `PART_TREE` 材质名、
   `pet.html` 的贴图预加载清单、`motions.js` 的 `MOTION_DEFS`。

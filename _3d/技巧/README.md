# 技巧 / 教程

Hermes 写的**学习与技巧类 Markdown** 都放这里（原来散在 `_3d\` 顶层）。

| 文件 | 内容 |
|---|---|
| `自己制作衣服教程.md` | 在 Blender 里自己做衣服（从零建件、绑骨、材质接线） |
| `Blender建模入门_做衣服.md` | 更细的 Blender 操作入门（快捷键、塑形、LoopTools、常见坑） |
| `服装重设计方案.md` | 换装功能的方案对比（改贴图 / 新建几何 / 外部素材三条路线） |
| `换装功能方案.md` | 换装功能架构（同一 PMX 内多套服装 + 互斥分组切换） |
| `素体式判断依据.md` | 怎么判断模型里哪一套是素体（避免导出时带上） |
| `骨骼绑定_查看与修改.md` | **怎么查一个部件绑了哪些骨骼、怎么改绑定**（4 种查法 + 4 种改法 + 5 个坑） |
| `面部表情制作.md` | **表情怎么做**（现有 65 个表情清单 / VMD 表情轨道 / **新增眼眶雕刻形态键 8 个** / 桌宠侧驱动 + 坑） |
| `裙摆骨摊平_手动操作.md` | 裙摆骨从圆锥面摊平的手动步骤（只改姿态、可 Ctrl+Z） |
| `换装穿模治理方案.md` | 换装后穿模的治理思路（去穿透 / 位移场 / 贴体） |
| `渲染设置_浏览器端.md` | **kafetools「渲染设置」在浏览器怎么实现**（渲染引擎 / 世界环境预设 / 透明，能力对照 + 3 个坑） |

> 配套脚本：
> · `_3d\tools\查看骨骼绑定.py`（只读体检：骨架指向、每个骨头的顶点数/权重和、死组、无权重顶点、L/R 分布）
> · `_3d\tools\导出PMX.py`（**一键重导 PMX**：参数已固定，`visible_meshes_only=False` 才不会丢隐藏的服装；改完模型跑一次 + 重启桌宠即可）

> 插件（部件快速提取 Part Extract）的使用说明不在这里，在 `_3d\addons\部件提取_使用说明.md`；
> 插件本体：`_3d\addons\part_extract.py`（也装到了 Blender 的 addons 目录）。

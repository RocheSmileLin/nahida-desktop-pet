# 纳西妲桌宠

一个跑在 Windows 桌面上的 MMD 三维桌宠：透明无边框置顶窗口 + three.js 渲染，配套一个浏览器端「调整台」用来实时调部件、表情、物理和相机。

> 本仓库**只包含代码 / 配置 / 文档**。模型、动作、贴图属于第三方素材，不入库，需自备（见 [素材准备](#素材准备)）。

---

## 功能

**桌宠窗口**
- 透明无边框、置顶、不进任务栏；拖动带惯性，松手会自然收尾
- 像素级命中测试：只有人物画到的地方接收鼠标，其余区域点击直接穿透到桌面
- 视线跟随光标、程序化呼吸、逐动作相机补偿
- 右键菜单：动作分组、物理开关、物理强度三档、三渲二开关、打开调整台、重启、退出
- 系统托盘图标 + 单实例锁（重复启动会唤起已有窗口）

**调整台（浏览器）**
- 部件开关 30 项，按头部 / 手部 / 腿部 / 上装 / 下装 / 背饰 / 其他 / 主体分组，带图标网格
- 套装预设：保存 / 另存为 / 重命名 / 删除，存于 `_3d/sets.json`
- 表情面板：36 个 MMD 形态键滑杆 + 预设（`expr_sets.json`）
- 灯光、材质、描边、物理重力、取景等全部参数实时生效并写回 `_3d/pet_settings.json`
- 内嵌实时预览（`viewer.html`），可切渲染 / 白模 / 线框 / 三渲二

**动作系统**
- 动作清单唯一来源是 `_3d/motions.js`，桌宠页与预览页共用，不在页面里各写一份
- 支持：整段播放、帧区间截取、静帧定格（`a == b`）、循环、逐动作相机补偿（`cam.aim`）、逐动作布料处理

## 环境

- Windows 10 / 11
- Python **3.9**（用到 PyQt5 的 QWebEngine，需要能装 `PyQtWebEngine` 的版本）
- 显卡无硬性要求，WebGL2 可用即可（核显实测流畅）

```bash
pip install -r requirements.txt
# 等价于
pip install PyQt5 PyQtWebEngine
```

## 运行

```bash
cd _3d
python pet_app.py          # 带控制台，能看到 [pet] / [pet-js] 日志
# 或
pythonw pet_app.py         # 无控制台，日常使用
```

启动后会在本机起一个静态服务：`http://127.0.0.1:8810`

| 页面 | 地址 | 用途 |
|---|---|---|
| `pet.html` | `/pet.html` | 桌宠本体（窗口内加载） |
| `settings.html` | `/settings.html` | 调整台，右键菜单「打开调整台」会用系统浏览器打开 |
| `viewer.html` | `/viewer.html` | 预览视口，被调整台以 iframe 嵌入 |

单实例锁端口 `47821`，HTTP 端口默认 `8810`（见 `_3d/petapp/paths.py`）。

仓库不含素材。把下面这些放到位才能跑起来，路径相对 `_3d/`：

| 路径 | 内容 | 说明 |
|---|---|---|
| `model/纳西妲.pmx` | 主模型 | 手臂、裙摆等骨骼命名需与 `motions.js` / 代码里的约定一致 |
| `model/tex/` | 模型贴图 | 约 38 张，文件名必须与 PMX 贴图表完全一致 |
| `motion/` | 动作 VMD | 当前清单用 8 个文件，具体见 `motions.js` 的 `f` 字段 |
| `images/` | 部件面板图标 | `<开关名>.png`，30 张左右；缺图会自动回退成「首字占位」，不会破版 |

缺素材时的表现：页面对应请求 404、模型加载失败、部件面板显示占位方块。启动日志里 `[pet] 模型加载失败 … 404` 就是素材没放对。

## 改动作要注意的几点

全部改 `_3d/motions.js`，不要碰页面里的动作表。

1. **`MOTION_GROUP_DEFS` 的下标必须跟着重算。** 它存的是 `MOTION_DEFS` 的数组下标，删了动作不改这里就会越界，右键菜单会渲染到一半抛异常 —— 表现是「右键完全没反应」（菜单的 `display` 一直没被设上）。
2. **`ik` 别填错。** VMD 用 FK 写腿的要 `ik: true`（关足IK），走 IK 轨 / D 链的要 `ik: false`。填反了腿会僵或撕。
3. **静止姿势不要用 `loop: true`。** `MMDAnimationHelper` 的 `resetPhysicsOnLoop` 默认开启，每次循环都会 `physics.reset()`，布料/头发会被瞬间拽回初始位置，看起来是每秒抽一下。两个办法：
   - 姿势每帧相同（坐姿这类）→ 用 `a: 15, b: 15` 定格成静帧；
   - 或者给该动作 `noPhys: true` 关掉物理（躺姿 / 坐姿与重力不兼容，本来就会把布料顶飞）。
4. **`noGrant` 按动作实测。** 付与会把父骨变换写进子骨，某些 FK 摆姿的动作必须关掉（`noGrant: true`）足的位置才对。
5. 改完跑一次自检：

```bash
python _check_sync.py
```

**预览页的坑**：`viewer.html` 用 `AnimationUtils.subclip(clip, ..., a, b)` 截段，`a == b` 会截出 duration 0 的 clip 导致播不了。桌宠页对 `a == b` 有静帧分支，预览页没有 —— 两个页面共用清单时要注意。

## 已知限制

- **坐姿 / 躺姿动作关闭物理**：模型整体下沉、大腿压住裙子时，物理刚体会被身体持续顶飞（实测每帧骨旋转中位 30°+，站立只有 3~5°），所以这几条动作走 `noPhys`，布料完全跟随动作形状。
- **单显示器、单实例**：窗口位置记忆按虚拟屏幕坐标存，多显示器拔插后可能需要「复位位置」。
- **模型与动作不入库**：模型贴图约 60 MB、动作约 22 MB，且属于第三方素材，`git clone` 后需自行补齐。
